## Settings you can find your way in

- Phone: Settings now has clear headings (Connection, Notifications and calls, Look and feel, Server, Tools for Claude, Help) so the cards no longer all look the same.
- "What changed" in Settings → Updates (phone and desktop) shows the patch notes of every version, not only in the popup after an update.

## Restart your server

- Settings → Updates now has Restart next to your server (desktop: "Restart server"), for when it looks stuck or offline in Hearth. It asks first, and warns when Claude is working.

## API keys

- A key can remember: one session for every call, or a session per name, so it remembers the code it worked on.
- You choose the models and effort levels of a key yourself, and set sliders for how much of the 5-hour session and of the week it may use before it stops.

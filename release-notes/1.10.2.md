## Clearer icons and tidier screens on the phone

- Icons that say what they do: a real paperclip for Attach, a key for API keys, a shield for server permissions, a chip for server memory, a plug for MCP servers, a star for skills, a gauge for usage limits and a contrast circle for appearance.
- Open/close arrows on settings cards are now proper arrows, and the back button in a chat matches the other buttons.
- Choices such as permissions, model and effort now wrap onto more lines instead of hiding behind a sideways scroll.
- "What changed" no longer breaks over two lines, and the add-a-computer form uses shorter hints.
- Less wasted space: cards inside cards are flat, cards are a little tighter, the Week and API value tiles are the same height, and the empty cost chart is hidden until there is something to show.

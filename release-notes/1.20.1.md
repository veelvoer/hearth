## Support fixes and a prompt that cannot disappear

- Support: "Fix with Claude" now sends the report into your own Hearth chat and opens it, so you watch Claude work on it right there. Pictures that came with the report are shown to Claude too.
- Pictures and files sent with a support request now reach you.
- A message you send is never lost: if the connection breaks, your text is back in the box, a restarting server gets three quiet retries, and a run that never reached the disk still shows in the chat list as interrupted, with your prompt in it.
- Error messages now say what is wrong ("Can't reach Tufna. Is it on, and on the same Wi-Fi?") instead of Java and proxy codes.

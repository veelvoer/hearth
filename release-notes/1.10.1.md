## Updates that work wherever Hearth is installed

- Linux: an app that you unpacked from the AppImage (a folder, started from your app list) now updates itself: the new version is unpacked into the same place, checked first, and put in place in one step. If anything is wrong the app you have keeps working. Before, it opened a .deb installer that does not fit such a copy.
- Linux AppImage file: the new file is downloaded next to the old one and replaces it in one step.
- Linux package install on a computer without .deb support (Arch, Fedora and more), or in a folder that is read-only: Hearth moves to an AppImage in your own folder (~/Applications) with a launcher entry, and updates itself from there.
- Downloads are retried on a bad connection and checked (size and checksum) before anything is installed. A failed update says what went wrong and where to download the new version by hand.
- Windows portable: the new version is put in place of the old file automatically.
- A fix for a crash risk: every file the app needs is checked to be inside the installed package.

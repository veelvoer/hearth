## Fixed

- **Plans now really appear.** Claude Code switches its task list tools off when it runs in the background, so no plan was ever made. Hearth now switches them on, and Claude makes the checklist for every task (not for a plain question) and ticks the steps off as it works.
- **The plan shows everywhere.** In a chat on your computer and your phone, a Plan card sits above the message box: a check for each step that is done, a turning ring for the one Claude works on now, an empty ring for what is still to come, and a bar that fills up. When every step is done it folds to one line; tap it to open it again. On the watch the checklist is under the card at the top of the chat.
- The steps of the plan no longer show up as tool calls in the chat; the Plan card shows them instead.
- Plans and your API key need the Hearth server to be on this version: update it from the app (Settings, Updates).

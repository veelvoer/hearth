## Make MCP servers easily

- New: let Claude build an MCP server for any program or service (Inkscape, Onshape, a web API, a command line tool). Desktop: project tools → Connections → "Let Claude build one for you". Phone: Settings → Make an MCP server.
- Claude finds out how the program can be controlled, writes the tools, tests them for real with a built-in checker, and connects the server to Claude. A starter kit with no dependencies is included, so the result is small and reliable. You may be asked for an API key, which is never written into files.

## Delete chats

- You can now delete a chat (desktop: side panel → Delete; phone: chat options → Delete this chat). It asks first and goes to a trash folder on the server for 30 days, with an Undo on desktop.
- Desktop: "Delete all chats of this project" at the bottom of the list needs you to type the project name, so it cannot happen by accident.

## A stuck server comes back by itself

- Hearth now watches its own server program. When the server stops answering (it hangs, or it runs out of memory and crawls, so chats do not load), it is stopped and started again after a couple of minutes, without anyone logging in to it. It gives up after 5 restarts in 10 minutes, so the service manager can take over.
- When the server cannot be reached, the app says so and offers Restart right there: in the chat list on the phone and desktop, and in Settings → Updates.
- The server only needs to be updated once for this (the update itself restarts it).

## Fixed

- **A project made on your phone or server now arrives on your laptop by itself.** Before, a new project waited for your OK ("a new project is waiting") and nothing else happened if you missed that card, so the folder never appeared. Now it is copied into your projects folder at once (a project you rejected earlier stays away), and you get a notification: "New project: smplanner, added to your projects folder".
- **Sync is faster.** Files are checked every 6 seconds instead of 12, and the server tells your other devices the moment a file changes: when a device sends a file, when a file is deleted, and a few seconds after Claude edits files during a run, so changes follow while Claude is still working.
- Git folders sync without conflict copies (also in the Node version of the computer relay).

## Changed

- The "Install / Reject" card for new projects is gone, since projects now come by themselves.

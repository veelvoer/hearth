## What is new

- Hearth in Rust, as extra downloads to try next to your current apps (they do not replace anything):
  - Desktop for Linux and Windows (`Hearth-rust-…`): a native window instead of a web page. It uses about 32 MB of memory and almost no processor time when idle (the current desktop app uses about 435 MB).
  - Phone and watch apps (`Hearth-rust-phone-….zip` and `Hearth-rust-watch-….zip`, unzip them first): they install as separate apps. These are early versions: they have not been tried on a real phone or watch yet, and calls, deleting a chat and some settings are not in them yet.
  - The server installer `hearth-server` (a single static program).
- The Rust desktop app and the new Rust server installer both read your Oxide colors.

## Behind the scenes

- The relay's tests are now written in Rust (27 test files) and run on every change.

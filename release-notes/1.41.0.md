## What is new

- Hearth in Rust, to try next to your current apps (nothing is replaced). Open the phone app: Settings → Updates → Hearth in Rust → "Install the Rust phone app". The same files are on the release page "Hearth … in Rust (early versions)":
  - Desktop for Linux and Windows: a native window instead of a web page. It uses about 32 MB of memory and almost no processor time when idle (the current desktop app uses about 435 MB).
  - Phone and watch apps: they install as separate apps. These are early versions that have not been tried on a real phone or watch yet; calls, deleting a chat and some settings are not in them yet. The watch app is installed on the watch with adb.
  - The server installer `hearth-server`, one static program.
- The Rust desktop app and the new Rust server installer read your Oxide colors.

## Behind the scenes

- The relay's tests are now written in Rust (27 test files) and run on every change.

## Times

- Every message you send, every answer from Claude and every action Claude starts now shows the time (phone and desktop). Older messages show the weekday or the date.

## Status bar

- New setting Settings → Notifications → "Icon in the status bar". Off by default: Hearth's messages and alerts only show when you pull the notification bar down, with no icon next to the clock, battery and network. Friend requests and calls still pop up.

## Support mail

- When a support request or follow-up arrives, you get a notification with three choices: Give to Claude (starts a chat with the mail), Add to list (saved in Hearth and put on Google Tasks), or Ignore. On desktop a small window shows the same three buttons.
- Google Tasks: run `node scripts/google-tasks-token.js <client-id> <client-secret> <server-address> <server-token>` once (needs a Google Cloud OAuth "Desktop app" client with the Tasks API on). Without it, "Add to list" still saves the mail in Hearth.
- The support service needs SUPPORT_RELAY_TOKEN (your server's key) in /etc/hearth-support.env to tell your server about new mail.

## Fixes

- Desktop notifications for usage-limit questions were skipped; they show now.

## API keys

- New: Settings → API keys. Make a key for your own apps, so they can use Claude through your server on your plan's usage instead of API credits. Choose Low usage (light models and effort), High usage (strong models) or General (everything), and set a daily limit, a point of the weekly usage where the key stops, and an expiry date. The key is shown once, and you can revoke or delete it any time.
- With model "auto" Hearth picks the lightest model and effort that fits each request, within what the key allows.
- The call works like the normal Claude messages API (`POST /v1/messages`). A step-by-step guide with examples for curl, Python, JavaScript and the Anthropic SDK is in docs/API.md.

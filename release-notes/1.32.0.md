- New: "Continue in Claude Code". Every Hearth chat is a real Claude Code session, and your computers keep each other's chats up to date. In a chat, one tap shows the command to carry on with the same chat in Claude Code itself. On the computer it can open a terminal for you, already in the chat.
- New: Hearth for Wear OS watches. A calm, minimal screen: your session usage as a ring around the edge, your latest chats, the last answer of a chat, reply by voice and stop a run. The watch gets your servers from the phone app by itself. Download Hearth-watch-1.32.0.zip from the release page, unzip it and install the app on your watch.
- Smaller polish: Read aloud is now an icon next to Copy and Share.

## Fixed

- A server (or computer) that is almost full can update again: an update no longer keeps a copy of the old version, and copies that earlier updates left behind are removed the next time Hearth starts. Every version stays available on GitHub.
- The phone app deletes the file of an earlier update.

## Changed

- The Rust phone and watch apps (from Settings → Updates → Hearth in Rust, or the "in Rust" release page) now take the place of the current apps instead of installing a second copy: same app, same key. Your servers have to be paired again in the Rust app.
- The release page "in Rust" no longer repeats files that are in the main release.

## Server permissions (root rights)

- Root status is now checked for real: Settings shows "Ready" or exactly why not, with a "Check again" button and a copy button for the sudoers line.
- "Run as root" only appears when root actually works.
- Each chat has a Root rights card to add or remove root (desktop).
- A root chat continues without root, with Claude told, if root is turned off later.
- Stopping a root chat now really stops it; files keep the normal owner afterwards.
- Friends' prompts in shared chats never run as root.

## Support you can follow, and a server that restarts itself without a lock-out

- Support: every request now shows where it stands: Open, On the list, Answered or Fixed. Requests are grouped that way, and a fixed one no longer asks what to do with it.
- Support: when the sign-in has ended you are taken to the sign-in page with a code by email, instead of an error with no way forward.
- Support: you can attach up to three files (1.5 MB each) to a request or a reply. They go along in the email to us.
- Support on the phone: the keyboard no longer hides what you are typing.
- Server: wrong tokens from an old phone can no longer lock you out. The right token always gets in, so Restart in the app works again.
- Server: `hearth-server restart` (also stop, start and logs) now exists, and `hearth-server update` really updates instead of only showing a command.

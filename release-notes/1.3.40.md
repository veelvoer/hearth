## Chats that would not load

- One damaged or unusual chat file on a server no longer keeps all the other chats from loading. Such a chat is skipped, the rest shows.
- On desktop, every computer is asked for its chats at the same time, with a time limit, so one that hangs can no longer hold up the others.
- On the phone, when a server cannot load its chats, the message now says why instead of only "can't be reached".

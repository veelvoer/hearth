## Chats that vanished after a run with root rights, and a way to see what went wrong

- Found a second cause of "the chat vanished and I get Relay error 500": a run with root rights leaves chat files that belong to root. The server could not read them, so the chat disappeared from the list and opening it failed. The server now notices this and gives the files back to its user by itself, also when it starts and when a run ends.
- When something goes wrong in a chat, tap Details to read the server's own last lines, or Report to send them to support with one tap.

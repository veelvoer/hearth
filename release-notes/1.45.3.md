## Fixed

- **Project sync no longer floods itself with copies.** A big git project (hundreds of thousands of files in its .git folder) made every sync round find "conflicts" between identical git objects, create a copy of each, and then send those copies around again: sync slowed to a crawl and grew without end. Git's own files now sync without conflict copies (git objects are the same wherever their name matches, and for the other git files the newest wins), and old conflict copies inside git folders are no longer synced.

## Many projects, less clutter

- Desktop: the project tabs show your four most recent projects. All the others are behind one button, "All N projects", with a search.
- Delete a project from that list (⋯). You type its name first. The folder and all its chats go to a trash on the server for 30 days, and you can undo it right away or restore it later from the same list (Trash).
- Phone: press and hold a project (New session) to delete it, or a chat in the list to delete just that chat.

## Fixes

- When Claude's login has expired, the chat now says so in plain words and how to fix it, instead of "Claude reported an error". Hearth also renews the login early and one run at a time, so several chats no longer race for it.
- A new-version notice on the phone now opens Settings → Updates (it opened History).
- The usage on Home loads faster when one of your computers is offline.
- The update popup on the desktop no longer comes back for the same version, and sync leftovers can no longer trigger it.

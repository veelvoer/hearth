## Skills

- Skills you installed with the official Claude skills tools now show up: the ones synced from your Claude account (docs, pdf, xlsx and more), skills a few folders deep, and skills of installed plugins even when the plugin command is unavailable.
- Add skills inside the app: paste a GitHub link (owner/repo, or a link to one skill folder) or the text of a SKILL.md. Desktop: in a chat, Tools → Skills. Phone: Settings → Skills. Skills you added can be removed again.

## Workflows

- A chat can now work through steps by itself, each for a time you choose, so it no longer stops after about 20 minutes. For example: bug test for 2 hours, then fix every bug it found, testing each build on a connected debug phone.
- Set it up from a chat: Options on the phone (Workflow), or the Workflow card in the side panel on desktop. Pick Bug test, Bug fix or your own steps, set the minutes, and start. You can pause, skip a step or stop at any time.
- If your usage runs out in the middle, the workflow waits and carries on when it is back.

## Notifications

- Notifications that wait for your decision (usage limit, friend requests) always pop up on the phone, also when status bar icons are off.
